# Generated reports

Run the milestone commands from the repository root to create:

- `data_quality_report.json`
- `sql_business_summary.csv`
- `r_statistical_summary.csv`
- `r_group_summary.csv`
- `price_by_category.png`
- `age_vs_price.png`
- `regression_diagnostics.png`

Generated reports are intentionally ignored because they may contain aggregated
information derived from access-controlled competition data. The code and tests
needed to reproduce them are public.
